# 자습 출석 시스템

NFC 태그 + Google Apps Script + Google Sheets로 만든 고등학교 자습실용 자동 출석 시스템입니다.
학생이 NFC 태그를 통해 학생 페이지를 열고, **1부/2부/3부** 각 시간대에 [입실하기] 버튼을 누르면 그 즉시 출석이 확정됩니다 (퇴실 절차 없음).

## 구성

```
attendance-system/
├── index.html      학생 페이지로 안내(리다이렉트)
├── student.html     학생용 페이지
├── student.js        학생 페이지 로직
├── admin.html         관리자 페이지
├── admin.js            관리자 페이지 로직
├── style.css            공통 스타일 (학생 페이지)
├── admin.css              관리자 페이지 전용 스타일
└── README.md (이 파일)

google-apps-script/
└── Code.gs        백엔드 전체 로직
```

## 동작 방식

1. 학생이 NFC 태그(하나만 사용)에 휴대폰을 태그 → `student.html` 열림
2. 최초 1회, 학번 입력 → 서버에서 이름 확인 → **"이 휴대폰을 출석 기기로 등록"** → 서버가 발급한 기기 토큰을 휴대폰에 저장 (대리출석 방지, 한 학번당 최초 1회만 등록 가능)
3. 접속할 때마다 서버에 "오늘 내 부별 상태"를 물어봐서, 1부/2부/3부 각각 **"출석 완료" 또는 "미참여/참여 가능"**을 보여줌
4. 지금 시간대에 해당하는 부가 아직 출석 전이면 그 부의 [입실하기] 버튼을 보여줌
5. **버튼을 누르는 즉시 그 부의 출석이 확정됨** (퇴실 절차 없음, 체류시간 조건 없음)
6. 각 부는 서로 완전히 독립적으로 관리됨 — 1부를 안 했어도 2부부터 정상적으로 참여 가능
7. 모든 기록은 Google Sheets(Logs 시트)에 저장되고, 관리자 페이지(`admin.html`)에서 부별로 조회 가능
8. 출석이 확정되는 즉시, 별도의 외부 출석체크표 스프레드시트에서 해당 학생·해당 부·해당 날짜 셀이 자동으로 노란색 표시됨 (신청 여부와 무관하게 실제 출석한 부는 항상 표시)

## 부별 시간표

기본 시간표는 다음과 같습니다 (Code.gs의 `PART_SCHEDULE`에서 변경 가능, 반드시 `"HH:mm"` 두 자리 형식으로 입력):

- **1부**: 17:00 ~ 18:00
- **2부**: 19:00 ~ 20:20
- **3부**: 20:30 ~ 21:50

입실은 반드시 그 부의 시간대 안에서만 가능합니다. 시간대를 벗어나면 입실 버튼 자체가 뜨지 않습니다.

## Google Sheets 구조

**Students 시트**: `학번 | 이름`

**Devices 시트**: `학번 | 이름 | 토큰 | 등록일시 | 상태` — 학생별 출석 기기 등록 정보.

**SecurityLogs 시트**: `시각 | 학번 | 시도유형 | 결과 | 사유` — 기기 인증 성공/거부, 관리자 초기화 이력.

**Logs 시트**: `날짜 | 학번 | 이름 | 부 | 입실시간 | 퇴실시간 | 체류시간(분) | 출석상태 | 비고`

퇴실 개념이 없어졌으므로 **퇴실시간, 체류시간(분) 열은 항상 빈칸**입니다. 출석상태는 입실 성공 시 항상 `"출석"`으로 기록됩니다.

## 학생 기기 등록이 막혔을 때 (기기 초기화)

브라우저 데이터 삭제, 새 휴대폰으로 교체, 특히 **아이폰 Safari가 오래 안 쓴 사이트의 저장 데이터를 자동으로 지우는 경우**(며칠 이상 접속 안 하면 발생 가능) 등으로 학생이 재등록을 못 하고 막힐 수 있습니다.

이 경우 관리자 페이지(`admin.html`)에서:
1. 필터 바 아래 **"초기화할 학번 입력"** 칸에 학번 입력
2. **"기기 초기화"** 버튼 클릭
3. 학생에게 다시 등록을 시도해보라고 안내

Devices 시트를 직접 열어서 수정할 필요 없이 관리자 페이지에서 바로 처리됩니다.

## 설정이 필요한 값

| 위치 | 값 | 설명 |
|---|---|---|
| `Code.gs` | `ADMIN_PASSWORD` | 관리자 페이지 비밀번호 |
| `Code.gs` | `PART_SCHEDULE` | 1부/2부/3부 시작·종료 시각 (`"HH:mm"` 두 자리 형식 필수) |
| `Code.gs` | `ATTENDANCE_SHEET_ID` | 외부 출석체크표 스프레드시트의 **ID만** (URL 전체 아님) |
| `student.js` | `WEB_APP_URL` | Apps Script 웹 앱 배포 URL (`script.google.com/.../exec`) |
| `admin.js` | `WEB_APP_URL` | 위와 동일한 값 |
| `admin.js` | `GOOGLE_SHEET_URL` | 이 시스템의 스프레드시트(Students/Logs가 있는 곳) 바로가기 링크 |

## ⚠️ 알려진 보안 한계

- **학번 대리 입력 자체는 기기 등록(토큰) 방식으로 상당히 방지되지만, 완벽하지는 않습니다.** 등록된 휴대폰을 다른 학생이 물리적으로 빌려 쓰는 경우까지는 막을 수 없습니다.
- **학교 네트워크/위치 검증은 포함되어 있지 않습니다.** (GPS 반경 검증 추가를 검토 중입니다 — 학교 근처가 아니면 입실을 거부하는 방식이나, 위치 조작 앱으로 우회될 가능성은 있습니다.)
- **관리자 비밀번호는 단순 고정 비밀번호 방식**입니다. 세션 관리나 해싱이 없습니다.
- **입실 즉시 출석이 확정**되므로, 태그만 찍고 바로 자리를 뜨는 것을 막는 별도의 체류시간 조건이 없습니다.

## 앞으로 개선 가능한 부분

- GPS 기반 학교 반경 검증 추가
- 학교 네트워크 검증 모듈 연동
- 관리자 인증을 Google 계정 로그인 방식으로 전환
